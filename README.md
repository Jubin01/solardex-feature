# Solar system Vue app for low powered devices

Simple solardex app, similar to the pokedex for pokemon.

Demo at https://sdx-fe.web.app/#/

Currently only planet (and also two moons) images are shown.
Descriptions are sourced using space object names from wikimedia api, so the  moons descriptions may be wrong.
